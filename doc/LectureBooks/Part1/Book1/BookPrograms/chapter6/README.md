# Programs for chapter 6

Every number, table and figure of chapter 6 is produced by the programs in this folder, on top of the shared modules of chapters 2–4 (`../common/statevector.py`, `circuit.py`, `gates.py`, `pauli.py`, `models.py`, `matrixfunctions.py`) and the chapter-4 programs `mapped_models.py` (Lipkin doublet encoding) and `pauli_circuits.py` (compact pairing Hamiltonian, Trotter-step circuits). Keep this list and the `Programs for this chapter` section of `chapter6.tex` in sync. Figures are written to `../../BookFigures/chapter6/`.

| Program | What it computes | Runtime |
|---|---|---|
| `qft.py` | `qft_circuit(n)` (Hadamard / controlled-R_k / SWAP as a `Circuit`, with optional truncation and no-swap variant), `qft_matrix`, the product form built without a circuit, four verifications (matrix, product form, `numpy.fft`, inverse), the worked example QFT_8\|101> (Fig. 6.qftphases), gate counts (Table 6.qftcost), approximate QFT (Table 6.aqft, Fig. 6.aqfterror), bit-reversal check | ~1 s |
| `phase_estimation.py` | `PhaseEstimation` class on the state-vector simulator (controlled matrices or the eigenbasis method), `dirichlet_probability`, signed phase → energy, `choose_time` from the Pauli 1-norm, `iterative_phase_estimation` (one control qubit); exact example φ=5/8, Table 6.inexact, Fig. 6.dirichlet, the 4/π² and 8/π² bounds | ~1 s |
| `qpe_models.py` | QPE on the tapered one-qubit pairing Hamiltonian and the two-mode Hamiltonian (Tables 6.onequbit, 6.twoqubit); the four chapter-4 models (Table 6.models), QPE vs. register size (Table 6.qpemodels, Fig. 6.modelerrors), time-step comparison for the Hubbard ring; Trotterized evolution inside QPE on the Heisenberg ring (Table 6.trotter, Fig. 6.trotterbudget); trial states and overlaps (Table 6.overlaps), Lipkin spectroscopy at χ=2 and QPE as state preparation (Fig. 6.spectroscopy) | ~10 s |
| `hhl.py` | `HHL` class (ancilla + clock + system, uniform or sine-window clock, signed eigenvalues), the 2×2 example and Table 6.hhlclock, the 1/κ² check, the discretized Poisson equation (Table 6.poisson, Fig. 6.hhlpoisson), the resolvent ⟨b\|(z−H)⁻¹\|b⟩ of the two-level pairing Hamiltonian (Fig. 6.hhlresolvent) | ~5 s |

Conventions: control/clock qubits come first (qubit 0 = most significant bit of the phase, controlling U^(2^(m-1))), the system register last; U = exp(−iHt) in `PhaseEstimation.from_hamiltonian` (phase −Et/2π) and U = exp(+iAt) in `HHL`; phases are read as signed fractions (leading bit 1 ↔ negative phase). All programs run on `numpy` and `matplotlib` only; each runs as a script with `assert`-based checks.
