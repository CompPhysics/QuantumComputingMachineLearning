Quantum Machine Learning#

Morten Hjorth-Jensen

This is the executable edition of the textbook. Every chapter is a Jupyter notebook that carries the full text of the printed chapter, its equations with the same numbers, its figures and tables, and the programs that produced them. The code cells are not illustrations added afterwards: every number quoted in the text is printed by one of them.

How the book is organised#

Each chapter takes a classical machine-learning model, derives it in enough detail to implement it, replaces one of its components by a quantum circuit, and runs both versions on the same data with the book’s own state-vector simulator.

Running the code#

The notebooks import the programs of the book rather than repeating them, so they are meant to be run from a copy of the repository:

git clone https://github.com/QuantumComputingQuantumMachineLearning/QuantumComputing.git
cd QuantumComputing/doc/Book/BookQML/Notebooks
pip install numpy matplotlib jupyterlab
jupyter lab chapter2/chapter2.ipynb

The first code cell of every notebook puts BookPrograms/chapterN/ and BookPrograms/common/ on the Python path. Each chapter ends with one cell per program of its Programs for this chapter list, which runs the program and shows the figures it wrote to BookFigures/chapterN/. The programs need only numpy and matplotlib: the qubit simulator, the feature maps, the quantum kernel and the support-vector machine solver are all written out in the book’s own classes, so that the mechanics stay visible. The optional PennyLane, Qiskit and scikit-learn cells run when those packages are installed and print a message when they are not. A whole chapter executes in one to two minutes.

The pages shown here were executed when the book was built from the LaTeX sources, and the outputs you see are the stored ones.
